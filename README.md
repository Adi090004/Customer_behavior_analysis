# Customer_behavior_analysis
Data analytic project showcasing customer behavior analysis using python,sql and power bi
📊 Data Analytics Project
📌 Overview

This project focuses on end-to-end data analytics using Python, SQL, and Power BI. The workflow includes data loading, cleaning, exploratory data analysis (EDA), database querying, dashboard creation, and report generation to extract meaningful business insights from raw data.

The project demonstrates practical skills in data analysis, visualization, and reporting commonly used in real-world analytics roles.

📂 Dataset
Source: Public/Company Dataset
Format: CSV / Excel / Database
Size: Multiple rows and columns containing structured data
Features may include sales, customers, products, transactions, performance metrics, etc.
